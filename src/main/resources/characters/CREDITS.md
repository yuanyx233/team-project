# Character art credits

The images in this folder are from **32-pixel Human Sprites** by **cyanowl**, published on
OpenGameArt: https://opengameart.org/node/20859

Licence: **CC0 1.0 (public domain dedication)**. No attribution is required; it is given here
as thanks and so the source is easy to find.

| File | Contents |
| --- | --- |
| `human_sprites.png` | Body sheet: walking frames in two skin tones |
| `human_sprites_hair.png` | Hair pieces: two female styles in four colours, one male style in three colours |
| `human_sprites_0_HOODIE.gif` | Hoodie layer |
| `human_sprites_0_JEANS.gif` | Jeans layer |
| `human_sprites_0_SHOES.gif` | Shoes layer |
| `Human_Sprites_Smooth_SideWalking_strip8.png` | Eight-frame side walk (body only) |

The files are unchanged. The game composes and recolours characters from them in Java
(`view.map.CharacterSheet`); the backpack and cap are drawn in Java.
